\# GeoSense



GeoSense is a geospatial site intelligence project.



\## Phase 5: API and Frontend App



Phase 5 adds a FastAPI backend and a Streamlit frontend app.



\### Backend



Run the backend using:



```bat

uvicorn api.main:app --reload --port 8000

```



\### Frontend



Run the frontend using:



```bat

streamlit run frontend\_app.py

```



\### Test



Open the frontend at:



```text

http://localhost:8501

```



Click \*\*Get Site Score\*\* to generate a site score.

Phase 5 is complete.
